# 03 - خرید بلیت و مالی

خرید بلیت نباید همان لحظه برگزارکننده را بستانکار کند. درآمد برگزارکننده تا پایان رویداد فقط قابل محاسبه است.

```mermaid
flowchart TD
    A["کاربر بلیت می‌خرد"] --> B["ساخت TicketOrder"]
    B --> C["ثبت پرداخت / رسید"]
    C --> D{"پرداخت تایید شد؟"}
    D -->|نه| E["Order Pending/Rejected<br/>بلیت معتبر نیست"]
    D -->|بله| F["Order Confirmed<br/>Ticket معتبر"]
    F --> G["مبلغ فروش، کمیسیون و سهم برگزارکننده در Order ذخیره می‌شود"]
    G --> H["فعلا هیچ Credit برای برگزارکننده ثبت نمی‌شود"]
    H --> I["درآمد بالقوه تا پایان رویداد نگه داشته می‌شود"]
```

وضعیت‌های درگیر: `TicketOrderStatus`, `TicketOrderPaymentStatus`

لاگ‌ها: `DatingEventTicketPurchased`
