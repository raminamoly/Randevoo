# 04 - تغییرات رویداد

تغییرات سبک مستقیم ذخیره می‌شوند. تغییرات حساس، مخصوصاً بعد از فروش بلیت، باید درخواست تغییر بسازند و پس از تایید مدیر اعمال شوند.

```mermaid
flowchart TD
    A["رویداد در حال فروش"] --> B{"نوع تغییر"}
    B -->|سبک: توضیحات، تصویر، FAQ| C["اعمال مستقیم + لاگ"]
    C --> D["فروش باز می‌ماند"]
    B -->|حساس: زمان، مکان، قیمت، ظرفیت، روش پرداخت| E["ثبت درخواست تغییر"]
    E --> F["فروش موقتا بسته می‌شود"]
    F --> G["نسخه Live فعلی دست نمی‌خورد"]
    G --> H["مدیر بررسی می‌کند"]
    H -->|رد| I["درخواست رد می‌شود<br/>Live قبلی باقی می‌ماند"]
    I --> J["امکان باز کردن دوباره فروش"]
    H -->|تایید| K["تغییر روی Live اعمال می‌شود"]
    K --> L["اطلاع‌رسانی به خریداران/شرکت‌کنندگان"]
    L --> M["فروش قابل باز شدن دوباره"]
```

وضعیت‌های درگیر: `EventChangeRequestStatus`, `EventSaleStatus`

لاگ‌ها: `EventChangeRequested`, `EventChangeApproved`, `EventChangeRejected`
