# 08 - نظرسنجی رویداد

نظرسنجی فقط بعد از پایان رویداد و فقط برای شرکت‌کننده دارای بلیت معتبر فعال می‌شود.

```mermaid
flowchart TD
    A["رویداد Completed"] --> B["نظرسنجی فعال می‌شود"]
    B --> C["ارسال پیام/اعلان به شرکت‌کنندگان معتبر"]
    C --> D["شرکت‌کننده فرم نظرسنجی را ثبت می‌کند"]
    D --> E["امتیازها ذخیره می‌شوند"]
    E --> F["میانگین امتیاز برگزارکننده آپدیت می‌شود"]
    F --> G["گزارش کیفیت رویداد برای مدیر/برگزارکننده"]
```

وضعیت‌های درگیر: `EventLifecycleStatus.Completed`, `EventSurveyResponse`

لاگ‌ها: `EventSurveySubmitted`
