# 05 - لغو رویداد

لغو رویداد با بستن فروش فرق دارد. اگر بلیت تاییدشده وجود داشته باشد، برگزارکننده درخواست لغو ثبت می‌کند و مدیر تصمیم می‌گیرد.

```mermaid
flowchart TD
    A["درخواست لغو رویداد"] --> B{"بلیت تاییدشده دارد؟"}
    B -->|نه| C["لغو مستقیم توسط برگزارکننده/مدیر"]
    C --> D["Cancelled<br/>فروش بسته"]
    B -->|بله| E["ثبت درخواست لغو با دلیل"]
    E --> F["فروش بسته می‌شود"]
    F --> G["مدیر بررسی می‌کند"]
    G -->|رد| H["رویداد فعال می‌ماند"]
    H --> I["امکان باز کردن فروش"]
    G -->|تایید| J["Cancelled"]
    J --> K["Refund/اعتباردهی طبق سیاست"]
    K --> L["اطلاع‌رسانی به شرکت‌کنندگان"]
    L --> M["لاگ کامل مالی و عملیاتی"]
```

وضعیت‌های درگیر: `EventCancellationRequestStatus`, `EventLifecycleStatus.Cancelled`, `EventSaleStatus.Closed`

لاگ‌ها: `EventCancellationRequested`, `EventCancelled`
