## High-level findings
- Architecture: layered .NET solution with Domain, Application, Infrastructure, WebApi, Razor Pages AdminPanel, and test projects.
- API style: ASP.NET Core Minimal APIs plus a SignalR hub for event chat.
- Persistence: EF Core DbContext with 54 DbSet declarations and 39 migrations.
- UI: Razor Pages admin/operator panel with 63 detected pages.
- Known state: several features are partial or need verification, especially matching automation, notification delivery beyond console senders, production payment gateway behavior, and UI empty/error states.
